## Branch Strategy

The team will use a feature-based branching strategy to organize
development and collaboration.

- **Main Branch:** The main branch will contain the stable version of
  the project. Direct commits to main will be avoided.

- **Feature Branches:** A new branch will be created for each major
  feature or task.

- **Collaboration:** Team members working on the same feature will
  collaborate on the same feature branch.

- **Code Review:** Once a feature is complete, the team will review and
  test the changes together.

- **Merging:** After the feature has been reviewed and tested, the
  feature branch will be merged into main. Branch Cleanup: Feature
  branches may be deleted after they have been successfully merged and
  are no longer needed.
